# Bike Store Landing Page

A modern, responsive landing page for a bicycle store, focused on pixel-perfect layout implementation and clean styling structure.

* 🔗 [**View Live Demo**](https://Kit3AWP.github.io/Landing_Page_Bikes/)
* 🔗 [**Design from Figma**](https://www.figma.com/design/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0-1&p=f&t=nkVKC6tDThjy3qeT-0)

**Tech Stack**
* **Technologies:** HTML5, SCSS, Vanilla JavaScript
* **Methodology:** BEM (Block Element Modifier)
* **Build Tool:** Parcel

**Key Features**
* Fully responsive design (adapted for Mobile, Tablet, and Desktop screens).
* Interactive UI elements and smooth hover effects.
* Optimized assets and automated build process.

**Running Locally**
To run this project on your local machine, follow these steps:

1. Clone the repository:
   `git clone <link-to-your-repo>`
2. Install dependencies:
   `npm install`
3. Start the development server:
   `npm start`
